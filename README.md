# POLISIM 정책 모형실

지자체 정책을 블록으로 적고, 같은 가정 아래 수천 번 돌려 실패 원인·보완안을 찾는 데스크탑 앱

## 내려받기

[Releases](https://github.com/andy555-cmyk/polisim-web/releases/latest)에서 받는다

- 맥: `POLISIM-mac-arm64.dmg` (애플 실리콘)
- 윈도우: `POLISIM-windows-x64-setup.exe`

설치한 뒤에는 앱이 새 판을 스스로 확인하고 서명을 대조한 뒤 바꾼다

## 할 수 있는 일

- 정책 문법: 임대료·임차·행사·협약·홍보 블록 + 연차 계단(예: 1~4년차 100%, 5년차부터 50%)
- 외부 충격 블록: 수요 감소·임대료 급등을 원안과 미시행에 똑같이 걸어 비교
- 판정: 1·3·5·10년 통과·조건부·실패, 스트레스 시험 8종, 정책별 기여(하나 빼고 다시 돌림)
- 보완안 찾기: 블록 값을 바꿔 다시 1,000쌍 확인
- 사회 반응: 동네 단톡방·공개 게시판 두 경로의 여론 확산, 영향력 큰 인물, 인물별 기억 원장
- AI(구독 CLI: Claude·Codex·Grok): 말→정책 블록 번역, 문서 그래프, 합성 인물 설문·인터뷰, 보고 문장 정리

## 원칙

- 숫자는 계산 엔진만 만든다. AI는 번역·정리만 하고, 결과 표에 없는 숫자를 쓰면 표시한다
- 여론·인터뷰는 관찰용이며 빈 점포·비용 계산으로 되먹이지 않는다
- 인물은 모두 합성(가상)이다. 결과는 예측이 아니라 가정에 따른 모형 안 시나리오 판정이다
